# Access Matrix - ToDo

## Objetivo
Definir qué ve y qué hace cada usuario según:
- empresa activa
- rol
- módulo
- acción

## Para cada rol definir
- pantalla inicial
- módulos visibles
- acciones permitidas
- acciones restringidas
- datos que puede ver
- datos que puede editar
- flujo de navegación
- relación con otras empresas

## Regla
Ningún usuario debe ver o editar datos fuera de su empresa activa o de su rol.
