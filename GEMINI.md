## Regla crítica de diseño
No debes tratar Web y Móvil como la misma experiencia con distinto tamaño.

Debes asumir esto como obligatorio:
- Web y móvil comparten lógica, pero no deben compartir exactamente la misma experiencia visual.
- En Web se debe aprovechar espacio, paneles laterales, tablas, vistas maestro-detalle, filtros persistentes y densidad de información mayor.
- En móvil se debe priorizar foco, simplicidad, jerarquía clara, acciones rápidas, navegación compacta y menos carga visual por pantalla.
- No quiero una web que parezca una app móvil estirada.
- No quiero un móvil que parezca una web comprimida.
- Quiero dos experiencias coherentes entre sí, pero adaptadas a la naturaleza de cada plataforma.

En todas tus propuestas debes separar:
1. propuesta para móvil
2. propuesta para web
3. qué comparten
4. qué debe ser diferente
5. por qué esa diferencia mejora la experiencia

Tu tarea no es tocar backend.
Tu tarea es proponer y mejorar la experiencia visual real de la app.
